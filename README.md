# HR Analytics Cloud Warehouse

## Overview
Workforce planning and attrition analysis using Amazon Redshift.

## Technologies 
- Amazon Redshift
- Python 3.9+
- SQL
- Tableau
- AWS Glue

## Architecture
- Source: HRIS, ATS, Performance systems
- ETL: AWS Glue
- Warehouse: Redshift
- Analytics: Tableau

## Features
- Headcount analytics
- Attrition prediction
- Compensation analysis
- Performance metrics
- Diversity & inclusion
- Recruitment funnel
- Employee engagement
